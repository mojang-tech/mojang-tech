## 🎮 Featured Projects

### Cat Tracker
An immersive underwater adventure game where you control a fish to rescue falling cats!

**Features:**
- 🐟 Smooth physics-based movement with mouse/keyboard controls
- 🐱 Rescue floating cats and collect power-ups
- 🧲 **Magnet Power-up** - Automatically pull nearby cats
- 🛡️ **Shield Power-up** - Temporary invincibility from hazards
- 👾 Dynamic obstacles - Jellyfish and sharks
- 📊 Score tracking with high score system
- 🎨 Beautiful ocean-themed graphics and animations

**Tech Stack:** JavaScript, HTML5 Canvas, Responsive Design
